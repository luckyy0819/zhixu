# 知序智能问答设计

用户已确认个人版通用问答加文档工作台方向。

信息架构：新对话、文档工作台、历史会话、设置。首页围绕一个输入框组织，示例问题帮助启动。会话后输入框贴底，引用展开右侧资料面板。

视觉：冷灰白画布、墨绿品牌、薄荷绿强调，细边框、宽留白、克制圆角。左栏 248px，内容最大宽 860px；窄屏左栏改抽屉，预览改覆盖面板。尊重减少动画设置。

状态：空白、附件待处理、生成中、停止、完成、读取失败。所有演示回答标明模拟；自有文件不生成伪引用。

数据：本地会话存储仅用于原型；正文通过 textContent 渲染。附件正文留在内存，刷新后重新选择。真实产品数据路径见需求文档。

验证：脚本语法、空输入、文件格式及大小边界、示例分析、引用定位、停止生成、历史切换、移动端布局。
